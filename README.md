- 🌓 **Dark & Light Mode:** Seamless toggle with local storage persistence.

- 📂 **Project Showcase:** Filterable project cards (Wonderlust, Course Connect, SAP ABAP reports).
- 📜 **Interactive Resume Modal:** Quick in-browser preview and print/download option.

## 🚀 Live Demo & Deployment
You can host this website for free using **GitHub Pages**:
1. Push this repository to your GitHub account (`jatin-yadav0`).
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be live at `https://jatin-yadav0.github.io/<repo-name>/`!
